SR Hub – Dress Shop Management System

About the Project

SR Hub is a web-based Dress Shop Management System developed as a DBMS project. It helps organize dress shop operations through a web application built using Flask and MySQL.

Features

- Browse available dresses
- Search for products
- Shopping cart and checkout
- Vendor dashboard for managing shop activities
- Database management using MySQL

Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Database: MySQL

Project Structure

- "app.py" – Main Flask application
- "templates/" – HTML templates
- "static/" – CSS, images, and other static files
- SQL setup file – Database structure and setup

Installation and Setup

1. Install Python 3.

2. Install the required Python packages:
   
   pip install flask mysql-connector-python

3. Install and start MySQL.

4. Create the project database and import the provided SQL setup file.

5. Configure your database connection details securely.

6. Run the application:
   
   python app.py

7. Open the local URL displayed in your terminal.

Learning Outcomes

- Understanding database design and connectivity
- Integrating MySQL with a Python Flask application
- Developing a web application with frontend and backend components
- Applying DBMS concepts to a practical project
